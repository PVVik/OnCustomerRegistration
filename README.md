# OnCustomerRegistration

Здесь представлен небольшой pet-проект, реализующий площадку, где салоны красоты могут размещать свои услуги и время для 
записи, а клиенты, соответственно, могут просматривать эти услуги и записываться.

## Технологии
- Java 17, Spring Boot, Spring Web
- Bean Validation, Lombok

## Ветка add-salon-repository-controllers
Добавлена логика по созданию и валидации сущностей, отвечающих за управление салонами красоты, таких как сам салон 
красоты, мастер или специалист, услуга, окно для записи. 
### SalonController, список эндпоинтов:
| # | Метод | Путь | Описание                           |
|---|-------|------|------------------------------------|
| 1 | POST | `/salon` | Создать салон                      |
| 2 | POST | `/salon/{salonId}/services` | Добавить услугу в салон            |
| 3 | PATCH | `/salon/{salonId}/services` | Обновить услугу в салоне           |
| 4 | DELETE | `/salon/{salonId}/services/{serviceId}` | Удалить услугу из салона           |
| 5 | GET | `/salon/{salonId}/services` | Получить список услуг салона       |
| 6 | POST | `/salon/{salonId}/masters` | Добавить мастера в салон           |
| 7 | PATCH | `/salon/{salonId}/masters` | Обновить данные мастера            |
| 8 | DELETE | `/salon/{salonId}/masters/{masterId}` | Удалить мастера из салона          |
| 9 | POST | `/salon/{salonId}/masters/{masterId}/slots` | Добавить окно для записи к мастеру |

### Успешные ответы
| Код | Сценарий |
|-----|----------|
| 200 OK | Запрос выполнен |

### Ошибки и коды ответов
| Код | Сценарий | Пояснение |
|-----|----------|-----------|
| 400 Bad Request | Невалидные данные в теле запроса | Срабатывает Bean Validation (`@Valid`, `@NotBlank` и т.д.). В ответе — список ошибок валидации. |
| 404 Not Found | Ресурс не найден | Например, салон с `{salonId}` или мастер с `{masterId}` не существует. |
| 500 Internal Server Error | Внутренняя ошибка сервера | Непредвиденные исключения на бэкенде. |
